# 4.0.11 更新说明

本次正式发布汇总 4.0.7—4.0.11 测试版的改进。

- 优化太阳系多指缩放、平移和拖拽，减少触点切换时的跳动。
- 新增“上帝之手”：保留当前视角，拖动行星调整时间，松手即停；模式内禁止旋转、平移和缩放。
- 延长 XY 轴，修正季节地轴的俯视展示；地轴相对轨道法线保持 23.44° 倾角。
- 日期讲解环节结束自动回到现在并继续走时；暂停后继续使用已选日期。
- 日历增加二十四节气与重要节日，同日重合时同时显示。
- 日期选择新增“确认”：公历、农历和时间修改确认后统一应用；取消不改变画面时间。
- 测试环境和正式环境继续独立运行，保留各自的后台课程和维护内容。

已验证桌面及手机尺寸下的多指操作、斜视行星拖拽、连续讲解日期收尾、节气节日标注和日期确认流程。
