# v4.2.12 · 上帝之手与交互修复

正式发布日期：2026-10-03。本次提交汇总 v4.2.6 之后已上线的改动。

- 恢复独立“上帝之手”按钮，手机底部直接显示。普通模式拖动星球仅旋转视角，开启后才能拨动时间。
- 手动拨动时间后暂停播放，松手按速度产生衰减惯性；播放或“现在”退出该模式并恢复时间推进。
- 保留青色光带、粒子尾迹及渐隐效果。金色光环收敛为贴近星球的两段淡金色细弧，移除外圈与刻度。
- 优化双指缩放、拖拽阈值、模式切换和取消操作，避免误改日期或残留惯性。
- 复位保留坐标轴的显示状态，修复复位后再次开启坐标轴不显示的问题。
- 修复手机“更多”弹层被阿星、阿远讲解区域遮挡的问题。
