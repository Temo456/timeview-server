# 时间景观 4.1.2：手机端适配

## 更新内容

- 手机底部保留日期、时间播放和常用操作，其他观察工具收进「更多」；增加触摸目标尺寸，适配屏幕安全区。
- 竖屏讲解位于画面下方，横屏讲解位于右侧；支持展开阅读、收起看画面及章节切换。地球和课程聚焦根据可用空间调整位置。
- 信息卡默认展示摘要，可展开查看和关闭，减少对天体及讲解的遮挡；手机地球城市文字增加避让。
- 日期、农历、速度、时区、图层等弹层可独立滚动，适配短屏和键盘；保留明确的日期确认操作。
- 调整开场选择、操作引导和后台课程编辑的小屏布局。
- 桌面保留原布局和天文计算；手机布局切回桌面时恢复原工具栏节点与顺序。

## 验证

- Chromium 与 WebKit 手机模拟：320×568、390×844、844×390 的菜单、日期确认、公历/农历切换、讲解展开/缩小、章节切换、暂停续读、开场选择及后台弹窗。
- Chromium 触摸事件：地球双指缩放、太阳系双指缩放/平移、触摸取消、上帝之手锁定镜头及拖动行星改变时间。
- 桌面 1024×768、1440×900 的控件位置、尺寸与改动前基线对比；1365 和 1920 宽度下验证四季地轴、夏至冬至 Y 轴重合、聚焦和复位。
- 日期整句语音回归：`node tools/test-course-date-audio.cjs`。
- HTTPS 测试站：新资源哈希、版本号、课程与音频状态；旧缓存升级、手机横竖屏、恢复桌面、真实太阳系画面、刷新后复用已缓存的 182 条音频，未发现页面脚本错误。
- 无缓存首次访问首页：统一进度到 100% 后开场开始播放，进入地球正常；模拟顶部刘海与底部手势条安全区通过。
- 以上为浏览器自动化和引擎模拟验证，尚未在实体 iPhone/Android 设备上验收。
