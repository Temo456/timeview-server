# 时间景观 4.2.0 · 地球与太阳系同页切换

- 地球视角与太阳系视角合并到同一页面。切换不再重新打开文档、重放开场或等待 5 秒加载页；首次打开页面仍保留至少 5 秒的加载展示。
- 时间、暂停/播放状态及时间倍率随视角同步。太阳系增加“时/秒”倍率，两边的“月/秒”统一为 30 天，避免切换后速度变化。
- 两个视图共用讲解面板、段落记录、课程数据和音频缓存。课程跨视图连续讲解，手动切换会暂停讲解，继续时恢复到课程所在视图，结尾回到今天的地球。
- 保留地球缩放、半球和皮肤，以及太阳系相机和图层状态；切换时结束未完成手势和上帝之手模式，关闭旧画面的弹窗和资料卡。
- 太阳系首次进入时才创建 WebGL 场景，之后复用。隐藏视图暂停绘制，避免手机同时运行两套动画；资源初始化失败保留原画面，允许再次切换重试。
- 手机工具栏、农历/公历选择器和遮罩支持同页切换及横竖屏变化。旧太阳系与地球链接仍可访问；浏览器前进/后退可切换视图。

## 验证

- 本地 Chromium：桌面 1440×900、手机 390×844、横屏 844×390，包含实际双指触摸缩放、鼠标拖拽、相机恢复、暂停日期/倍率交接、阴阳历确认、连续快速切换、历史前进/后退、唯一 DOM ID 和隐藏视图停止绘制。
- 真实课程快照：从月相跨到二分二至保留对话；手动切走后继续回到课程；最后回到当前时间并继续运行。
- 初始化失败注入：首次太阳系贴图失败保留地球，清理监听和渲染资源后可成功重试。
- Windows WebKit：地球/太阳系往返、日历和运行中时钟交接通过。未进行 iPhone 真机 GPU 压力测试，Windows WebKit 的媒体解码也不代表 iOS 真机。
- 预加载 6 项、自然日期朗读和整句动态音频回归检查通过。
- 测试环境 HTTPS：4.1.6 旧缓存升级至 4.2.0，真实开场播放后连续往返，只加载 1 个文档、无脚本异常、无课程 MP3 重复下载；4 个入口路由和 15 个静态运行文件 SHA-256 核对通过。
