# 时间景观 4.1.1

## 更新内容

- 所选日期及时间改为整段语音合成，消除逐字拼接的生硬节奏；月份、日期按中文数词朗读，整点和个位分钟使用明确读法。
- 语音中的「廿、廿三、廿六」分别读作「二十、二十三、二十六」，页面保持原文字。
- 演示日期随课程预生成并统一加载；选择新日期时提前准备语音，生成后保存服务器和浏览器缓存，重复选择直接复用。
- 日期段落继续支持原位置高亮、暂停续读和跳过。

## 验证与发布

- 已发布至测试环境 `/timeview-test/` 和正式环境 `/timeview/`；测试课程修订 27、正式课程修订 29 各自保留，课程、知识库和配置分别维护。
- 测试课程 182 条音频中复用 176 条，重新生成 2 条农历读法及 4 条演示日期音频。
- 通过 `node tools/test-course-date-audio.cjs`：日期边界、闰日、时间读法、整句生成、并发去重、重启复用、课程快照隔离、旧清单拒绝及失败重试。
- 手机浏览器实际验证整句 MP3 播放、日期预加载、单段高亮、暂停续读、跳过、刷新复用和断网后读取已缓存日期。
- 正式环境 182 条音频全部就绪；HTTPS 页面版本、运行文件哈希、完整日期音频、缓存复用、MP3 解码和 Range 播放均已验证。
