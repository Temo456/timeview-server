# 4.2.6 · 单页视图与移动端播放

正式发布日期：2026-09-30。本次提交包含 4.1.3 之后的累计更新。

- 地球与太阳系合并为单页，切换保留日期、时间和讲解状态。
- 增加地球与太阳系之间的往返镜头动画，修正可见地球的返回拉近及移动端视口变化时的中断。
- 缩小手机城市名称并调整布局，避免重叠；完善移动端控制区。
- 加载页采用“观乎天文，以察时变”和“你的城 你的生日星空”，最低展示 5 秒。
- 调整 iPhone 开场视频的预加载、缓存分段读取和播放失败恢复。

- 微信内置网页在统一加载完成后显示“开始旅程（有声）”，点击启动开场，避免自动播放权限限制。
- 微信入口不再等待视频元数据事件，也不依赖 Service Worker 才能进入。
- 视频播放请求长时间无进展时恢复操作按钮，可重试或进入地球。
- Safari 和电脑端保留自动播放；统一进度、5 秒加载页和资源缓存继续保留。

正式环境：https://timeview.site/timeview/

测试环境：https://timeview.site/timeview-test/

正式与测试后台内容继续独立。正式课程 revision 29，184 条朗读音频就绪；测试课程 revision 27。发布前已备份正式数据并保留旧容器供回退。桌面 Chromium/WebKit 及策略模拟验证已通过，微信实机结果仍需确认。
