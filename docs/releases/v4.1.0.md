# 时间景观 4.1.0

## 更新内容

- 新增 15 秒北京升空开场，从天安门、中轴线、环路连续拉远至中国与地球；校正天安门正向构图和中轴线方向。
- 开场可选择北京或上海，保留有声播放、手机播放提示和片尾进入地球的衔接。
- 首页直接展示统一加载进度，提前准备开场、地球、太阳系和整堂课朗读音频；资源缓存在本地供重播使用。
- 后台保存、创建或发布课程后自动生成配套音频，全部就绪后发布；日期等动态讲解使用已缓存的语音片段组合。
- 修复首次开场被提前标记为已播放、等待下载超时的问题，临时下载失败自动重试一次。
- 完善桌面地轴倾角、夏至冬至与 Y 轴对齐，以及地轴颜色和线宽显示。

## 发布方式

- 正式环境使用独立的配置、课程、知识库及档案数据；先备份、预生成正式课程音频，再切换程序镜像。
- 测试环境与正式环境的数据、缓存路径和服务端口分别独立。
- Git 提交及 `v4.1.0` 标签对应本次发布；保留上一正式版本容器和备份用于回滚。
