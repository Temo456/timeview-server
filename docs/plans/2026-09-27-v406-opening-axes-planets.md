# 4.0.6：开场提速、课程 XY 轴保留与行星台词

## 需求与实现

- 旧开场在完整下载 8,209,251 字节后才把 Blob 交给播放器，导致首播长时间等待。将原片压缩成 960×540 的 H.264 / AAC MP4，保留 15.04 秒完整内容，文件 1,567,328 字节，元数据前置（faststart），首帧无需等待全片下载。
- 两个视图共用 `intro.js`，直接让 video 请求媒体并处理 Range 流式播放。资源名 `intro-v406.mp4` 配合 immutable HTTP 缓存加速重开；已播放过开场的太阳系页面不请求视频、不在后台播放。
- 讲解器根据已经过的脚本动作恢复 XY 轴保留状态，支持章节跳转与刷新。季节、行星、星座/星宿、探索和报告视图保留 XY；返回 XY 之前的章节重新按动作展示。Z 轴仅在显式讲 Z 时展示。
- 八大行星及冥王星分别使用特点简介，删除重复的“先看看它在画面里的位置，再读一读旁边的信息”。更新默认脚本，同时在备份后仅修改测试环境正在维护的主课程 11 段台词，其余章节、设置、新课程继续保留。

- `.deploy-check/v406-video.cjs`：浏览器模拟 5 Mbps / 80 ms，冷加载导航到首帧约 0.76 秒，其中媒体开始加载到首帧约 0.38 秒；重开导航到首帧约 0.33 秒。完整播放无二次缓冲，跳过及太阳系不重复加载验证通过。真实体验仍随网络、设备变化。
- `.deploy-check/v406-axes.cjs`：X→XY、五个季节动作、九个天体、星座/星宿/旅行者/三体、报告、复位、章节跳转及刷新后 XY 持续显示通过；回到 XY 前清除保留状态通过。
- 语法检查通过。压缩后画面抽帧检查通过。
