# 4.0.12 测试版：电脑端地轴投影修复

## 复现与原因

在 1365×900 和 1920×900 的电脑窗口中，进入夏至地球特写并打开右侧讲解框。几何地轴倾角仍为 23.44°，但俯视图中地轴与屏幕 Y 方向偏离约 39.64°；关闭讲解框仍偏离约 22.26°。手机视图未出现横向偏斜。

原因是聚焦布局通过横向移动透视相机为卡片让位。地球偏离相机光轴后，地轴的 Z 分量被投影成横向偏移。仅测试模型的三维夹角无法覆盖这个布局错误。

## 修改

- 显示地轴的地球特写保持相机正对地球，使用透视视口偏移为卡片和讲解框留出位置。
- 镜头过渡同时平滑更新视口偏移；切换其他主题或复位时清除偏移。
- 缩放锚点使用实际投影光心，窗口调整维持视口偏移比例，上帝之手继续保留原镜头。
- 模型实际倾角、纹理、地球大小和图层内容不变。

## 验证

- 1365px、1920px、390px，讲解框开/关、春分夏至秋分冬至：俯视地轴横向偏移误差小于 0.000001px，真实夹角为 23.44°。
- 双指缩放、滚轮锚点、上帝之手拖动日期、窗口调整、复位及切换其他行星通过。
- 普通模式双指平移缩放、触点增减、取消捕获、近景缩放和事件合并回归通过。
- 先部署测试环境，正式环境保留 4.0.11。
