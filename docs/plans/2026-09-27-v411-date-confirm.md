# 4.0.11 测试版：日期与时间确认

- 地球和太阳系日历底部增加“确认”，与“取消”“今天”并列，手机滚动时保持可见。
- 打开面板时以画面当前时间建立草稿。公历日期、时间、农历和时辰修改仅更新草稿；确认一次后更新画面并关闭面板。
- “今天”仅选择今天及当前时间；取消、点击外部或收起面板不应用修改，再打开时重新读取画面时间。
- 共享农历选择逻辑，支持闰月、大小月，以及公历/农历标签切换；保留精确到秒的时间，沿用各视图当前时区。
- 手动确认时暂停课程，避免下一句覆盖所选日期；维持原来的时钟播放状态。
- 验证 1000px/390px 下的两个视图：选择不提前生效、取消及重开、今天、确认关闭、时分秒精度、农历中秋转换、点击画布取消、空时间校验，均通过。
- 仅更新测试环境，部署前备份代码和维护数据。
