# 4.0.14：开场视频声音

- 首次进入和重播均优先有声播放，解除原有静音默认值，音量设置为 100%。
- 浏览器拒绝有声自动播放时，继续流式播放画面并显示“开启声音”；用户点击后在当前进度恢复声音。
- 若浏览器连静音自动播放也拒绝，提供“点击播放（有声）”按钮。
- 跳过或结束后暂停视频并隐藏按钮，防止过期播放请求影响新一轮开场。
- 保留 MP4 前置索引、Range 流式加载和会话内不重复开场的行为。

## 验证

- 原视频含 AAC 双声道，FFmpeg 检测到非静音信号。
- Playwright 使用真实 MP4 分别测试强制用户手势和允许自动播放两种浏览器策略，覆盖地球、太阳系以及 1365px、390px 窗口。
- 检查播放状态、静音标志、音量、音频解码、点击后进度连续、跳过、刷新不重复播放、重播与自然结束。
- 按用户要求直接部署正式环境，保留正式环境独立数据和旧版本备份。
