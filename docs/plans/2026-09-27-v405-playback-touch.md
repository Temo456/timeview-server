# 4.0.5：连续讲解、段落跳过与地球触摸缩放

## 用户要求

- 讲解自动接续，避免每段都要点击继续。
- 每个讲解段落可跳过。
- 地球视角支持触摸放大、缩小。

## 实现与验证计划

1. 复用一个语音播放器，在用户首次点击时授权播放；保持现有分句高亮、预加载和暂停后原段续读。处理失效异步回调，语音损坏时自动显示文字并继续。段间停顿缩短为 0.5 秒。
2. 每个正在讲解的段落提供“跳过本段”，取消该段播放或等待，接续后续讲解；暂停时跳过不自动恢复播放，互动问题仍保留答题机会。
3. 双指距离比例应用到地球缩放（0.5–4 倍），与鼠标滚轮范围一致；结束/取消手势后清理状态，避免单指残留导致日期跳变。
4. 浏览器验证真实媒体结束事件、模拟每个播放器需手势授权的策略、连续分句/段落、暂停原文续读、准备语音时跳过、播放时跳过、互动问题跳过、双指缩放边界及界面手势隔离。
5. 备份测试环境维护数据后发布测试版 4.0.5，核对健康、资源版本、数据校验和；正式环境保留 3.63。

播放器复用依据：[WebKit 自动播放政策](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)。该策略以媒体元素为单位授予许可，连续播放推荐替换同一元素的源。
