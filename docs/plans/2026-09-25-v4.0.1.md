# 4.0.1 聚焦、卡片与三体轨道实施计划

**目标：** 保持行星模型大小，通过镜头拉近聚焦；星座星宿全入口互斥；卡片统一在讲解框左侧顶部；部署测试版 4.0.1。

**实现：** 复用 Three.js 场景，删除课程模型缩放并加入镜头过渡。共享卡片定位脚本覆盖月相、节气、报告、行星、星宿与三体。图层 setter 负责互斥与标签同步。三体采用分层双开普勒近似，共用演示时钟，内轨道约 80 年、外轨道约 55 万年；外部距离压缩显示，不添加人为抖动。

## 步骤

1. 修改 `solar-system.html`：移除模型缩放，镜头平滑过渡，聚焦避开卡片；星座、星宿 setter 强制互斥并同步标签与控件。
2. 新建 `card-layout.js`，在 `index.html`、`solar-system.html` 引入，在 Dockerfile 中打包。所有内容卡顶部与右侧讲解框对齐，紧邻左侧；窄屏改为上方可滚动卡片。同一时刻展示一张内容卡。
3. 三体使用开普勒方程求位置，质量加权双星位置保持质心；完整连续轨道替代环形缓存折线；标签保留三维坐标。说明内外周期、空间压缩及演示时钟。
4. 更新 `server.js`、`sw.js` 为 4.0.1。服务器课程数据、用户新课程保持原文件。
5. 浏览器验证所有行星 scale 恒为 1、镜头连续移动，课程/手动图层互斥；桌面与窄屏卡片无重叠。验证三体周期、质心、等面积与轨道闭合，暂停不漂移。
6. 备份测试源码和维护内容，构建新测试镜像，替换测试容器；公网检查版本、场景和维护文件哈希。正式环境保持待用户验收后发布。
