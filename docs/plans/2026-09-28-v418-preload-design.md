# 4.0.18：统一加载后开始旅程

## 目标与取舍

用户希望把等待放在开场之前，资源准备完毕后再播放和进入地球。采用「完整预载 + 同页衔接」：统一在地球页面播放，视频结束后显露同页已经绘制好的地球。相比继续边播边载，这会增加首次启动前的等待，但消除片中下载和片尾重新加载地球；相比独立加载页，避免跨页面丢失已经解码的图片。

## 流程

1. 深色星空加载屏显示资源下载进度、已加载容量，以及开场动画、地球与月球、课程与界面三组状态。
2. 完整下载适合设备的视频，以及地球南北极、月球、嫦娥图标；图片解码、当前课程和界面初始化、地球首帧绘制完成后，进度才到 100%。
3. 播放视频使用本地 Blob，不再依赖边播边下载；浏览器允许时自动带声音播放，受限时保留开启声音入口。
4. 播完或跳过直接淡入已准备好的地球；同会话普通访问跳过视频，仍保证地球资源就绪再显露画面。
5. 从太阳系首次进入或重播开场时统一转到地球入口。普通太阳系访问保持原有场景加载流程。
6. 按部署路径和版本缓存成功下载的资源；网络/图片/视频失败停在可重试界面，重试复用成功缓存。

预载范围为当前开场与地球界面所需资源，不包含历史视频、未选择的皮肤或尚未请求的动态语音。

## 验证与发布

- 在慢网/延迟地球贴图条件下，确保视频始终停在 0 秒，地球未就绪时无法进入。
- 完整播放期间断网，验证视频无缓冲且片尾地球已显示；检查跳过、带声音播放、重播和普通访问。
- 验证资源失败与缓存重试、南北极图片、太阳系入口和课程初始化。
- 桌面/手机截图检查加载屏，发布测试环境并验证 HTTPS；保留旧测试容器和课程数据。

## 本地验证结果

- 延迟北极贴图，视频即使已完整下载/解码，也始终暂停于 0 秒；进度低于 100%，跳过按钮不显示。
- 资源齐备后，桌面断网完整播放 15 秒，900 帧丢 0 帧、播放中 0 次缓冲；片尾地球已解码并绘制，页面未发生跳转。
- 手机模拟 1.6 Mbps、100 ms 延迟、CPU 四倍减速：16.39 秒资源全部就绪，随后开始播放；播放期间断网，450 帧丢 0 帧、播放中 0 次缓冲，地球界面无需再次加载。
- 重播复用全部成功缓存，无重复的二进制资源网络请求；正常访问只准备地球，不重复播放开场。
- 模拟月球图片返回 503：正确显示失败提示和重试按钮，不播放、不进入未准备好的地球；恢复网络后重试成功。
- 手机音频、设备视频档位、跳过、太阳系开场转至同页地球、课程预览参数保留、普通太阳系入口均通过；桌面/手机加载屏截图已检查。
