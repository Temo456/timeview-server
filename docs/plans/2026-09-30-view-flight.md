# 地球与太阳系连续切换

## 设计

- 用约 1.3 秒的拉远 / 拉近，把地球表盘中的地球送到太阳系中地球的真实屏幕投影位置。保留青蓝光晕、少量星光拖尾，轨道随拉远显现。
- 保留两个场景的原有绘制，使用有像素预算的临时 2D 合成画布连接两个端点；不增加 WebGL 上下文、不下载动画素材、不同时运行两套场景。
- 地球端读取实际布局、缩放和地图旋转；太阳系端读取世界矩阵及相机投影。太阳系相机若已移出地球所在区域，返回时先恢复能够看见地球的构图。
- 暂停状态保持精确日期；运行状态按照原倍率计算动画终点时间，避免动画结束后时钟落后。课程等待动画结束再执行章节动作。
- 连续点击采用最新选择；窗口尺寸变化、页面隐藏、减少动态效果偏好可立即结束过渡，清理临时画布和事件。媒体、课程、开场不重建。

## 实施与验证

1. 为两种场景增加静态绘制及地球投影快照接口。
2. 实现轨迹、比例变化、场景渐显、地球图像衔接与临时画布回收。
3. 路由统一管理过渡生命周期、时间交接、历史和快速切换。
4. 验证桌面、手机竖横屏、WebKit、暂停/运行/快进、课程切换、反复操作、缩放后的真实落点、减少动态效果。
5. 版本 4.2.1，先更新测试环境，保留正式环境和独立维护数据。

## 验证结果

- Chromium 桌面、手机竖屏/横屏，以及 Windows WebKit 手机布局通过：双向落点、相机保留、暂停日期、运行时钟、连续反向切换、旋转屏幕、日历和减少动态效果。
- WebKit 切换 CSS 的首帧曾返回未完成布局的尺寸；增加原画面遮盖和两个渲染帧的布局等待，修复落点偏移。
- 额外检查冥王星特写后返回太阳系、连续中断六次，以及“年/秒”倍率；时间交接和画布释放通过。
- 单页课程跨章节、继续讲解、回到今天、历史前进后退、旧链接，以及加载页/日期朗读测试通过。
- 线上测试环境 4.2.1 已验证：从 4.2.0 缓存升级、开场实际播放、四次同页切换、农历日期选择；仅一个文档请求，音频缓存命中，没有 MP3 下载或页面脚本错误。
- 测试环境保留课程 revision 27 和 184 段音频；正式环境仍为 4.1.6。未使用 iPhone 真机验证 GPU / 内存压力。
