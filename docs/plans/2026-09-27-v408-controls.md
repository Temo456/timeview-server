# 4.0.8 测试版：轨道交互与日期收尾

- XY 轴单向长度至少 110，覆盖最外侧行星轨道，聚焦后不随镜头缩短。
- 普通模式统一调整视角；上帝之手切换到固定俯视全景，冻结自动走时，鼠标或单指拖动行星改变同一条时间线，松手即停。小行星扩大拾取范围，模型尺寸不变；地球拖动按实际太阳黄经反解日期。
- 日期互动及演示结束恢复当前时间、秒速和播放状态；暂停保持日期，继续完成后才恢复。月相、季节演示离开对应环节时恢复现在。
- XY 是轨道平面，Z 是法线；地轴在 YZ 平面内偏离 Z 轴 23.44°。季节特写保持俯视，地轴延长至投影露出球体。卡片分俯视与侧视，避免把倾角画在轨道平面内。
- 验证桌面与手机 Pointer Events、多指切换及缩放回归、拖拽日期与松手停止、四季轴向、日期暂停继续和自动收尾。
- 仅部署测试容器，保留后台维护数据和现有正式版本。

## 验证记录

- Chromium 原生触摸事件：1000px、390px，双指缩放和平移、触点增减、取消捕获、松手停止、60 步混合手势及每帧合并事件通过。
- 上帝之手：地球与海王星跟随触点改变日期，镜头保持固定，松手不漂移；退出恢复原播放状态，“现在”恢复秒速播放。
- 四季：轴向与 Z 轴夹角 23.44°，俯视投影沿 Y；二至地球位于 ±Y，二分位于 ±X。聚焦后 XY 轴长度仍覆盖外侧轨道。
- 连续讲解：日期互动、演示日期结束自动回到现在；报告暂停继续沿用所选日期；XY 保留跨章节、重载及复位回归通过。
- 测试容器 `timeview-test-v408`，镜像 `timeview:test-v4.0.8`。正式容器仍使用 `timeview:4.0.6`。
- 部署前代码和数据备份位于服务器 `/root/timeview-backups/before-v408-*.tar.gz`；课程文件、历史备份、新课程及知识库的部署前后 SHA-256 一致。
