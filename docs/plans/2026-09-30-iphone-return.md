# iPhone 返回动画中断排查

## 复现与范围

4.2.3 的 `views.js` 在每次 window resize 时结束当前切换，未区分屏幕旋转、移动浏览器工具栏改变高度、尺寸不变的重复通知。WebKit 触摸点击返回后，注入同尺寸 resize 或仅调整视口高度，100ms 内就从太阳系直接进入地球，真实相机推进被中断。固定尺寸设备模拟不能覆盖这个问题；尚未取得用户实体手机的事件记录，不能断言这是唯一原因。

## 修正方案

- 忽略尺寸未变的通知；触摸设备仅高度变化时维持动画，横竖屏或宽度变化才结束并重新布局。
- 返回相机逐帧获取地球页面目标几何，使浏览器工具栏变化后仍落在正确位置。
- 相机与合成动画按实际绘制的帧推进，限制单次时间步长，避免首帧等待或长任务吞掉整段动画。
- 同一帧内先推进相机再渲染；保留减少动态效果、后台切换、手动反向选择的退出路径。
- WebKit 截图进一步复现同宽度高度变化后 WebGL 内容空白，投影参数正确且没有 GL 错误。移动端同宽度调整复用绘图缓冲区，仅更新 CSS 尺寸和相机投影，修复后拉近过程及再次进入太阳系均实际绘制出行星。缓冲区分辨率沿用当前方向初始化尺寸，浏览器工具栏高度变化时不反复分配显存。
- 浏览器侧提供最近一次切换的只读诊断（阶段、结束原因、视口变更），不上传数据。

## 验证与交付

用实际 touch tap 覆盖窗口等尺寸通知、连续高度变化、30fps/长帧、旋转、中途取消、减少动态效果；断言太阳系仍在显示时地球逐步变大。保留桌面与课程状态回归，发布测试环境 4.2.4，实机确认仍需用户设备。

## 验证结果

- `tools/test-mobile-return-interruptions.cjs`：Chromium 与 Windows WebKit 手机模拟通过触摸点击、重复 resize、连续高度变化、恢复原始高度、950ms 长任务、约 15–30fps、横屏切换及减少动态效果检查。
- 增加截图像素断言，确认场景中确实有绘制内容；已人工查看 WebKit 拉近及再次进入太阳系的截图。尺寸变化后的空白截图会使该测试失败。
- `tools/test-visible-earth-return.cjs`：桌面顶部和底部入口、手机与 WebKit 的真实相机拉近、取消、日期和观察位置保留检查通过。
- 课程月相日期、跨视图章节、手动暂停继续和回到现在的回归通过。
- `node --check` 与 `git diff --check` 通过。服务器候选镜像的版本、资源哈希、路由和音频就绪检查通过。
- 用户尚未提供实体 iPhone 的系统版本、浏览器或事件记录；上述已复现并修正的路径仍需结合实机结果确认。
- 已部署 `https://timeview.site/timeview-test/` 的 4.2.4，课程 revision 27 和 184 条音频保留，正式容器未变。公网旧缓存升级、实际触摸返回、重复 resize 后仍继续拉近、日历、前进后退与音频缓存检查通过；4 次切换只加载 1 个文档，0 条音频重新下载，页面无 JavaScript 错误。
