# 4.0.9 测试版：上帝之手保留当前视图

用户澄清：上帝之手应在任意当前视图中拖拽行星，禁止其他旋转、平移、缩放，不要求切换到俯视图。

- 进入时只取消镜头动画和惯性，冻结自动走时；保留镜头位置、旋转角度、缩放、图层及卡片状态。
- 使用已变换的轨道平面进行射线求交，鼠标和触摸都沿当前投影轨道拖动行星、推进日期；松手即停。
- 窗口调整大小不退出此模式，也不自动重新聚焦；退出后恢复普通观察操作。
- 地轴维持相对轨道法线 23.44° 的真实模型夹角。屏幕投影角度随观察方向而变，不为视觉效果修改真实倾角。

验证：1000px / 390px，三组斜视（含接近侧面）、平移和缩放后的模式切换、鼠标及原生触摸拖动、地球近景、窗口调整、松手停止、退出恢复，以及地轴几何夹角通过。仅发布到测试环境。
