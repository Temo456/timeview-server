# 4.0.7 太阳系多点触控修复

## 已定位问题

- Pointer Events 与 Touch Events 同时驱动旋转、日期和缩放，多指共用单指拖拽坐标，产生互相覆盖。
- 缩放没有配套双指平移；手指加入、离开、取消、失去捕获没有统一基准。
- 惯性速度按固定 16 ms 估算，且多指操作时仍可能继续惯性或被课程镜头覆盖。
- 标签在场景旋转之前投影，可能比渲染画面滞后一帧；隐藏的星空标签也每帧计算，日期文字每帧重写。

## 方案

统一使用 Pointer Events，以 pointerId 记录手指位置并在渲染帧内合并处理。单指旋转、双指同时平移与缩放，缩放围绕双指中点的场景位置；手指数变化时先结算再重新建立基准，不继承过期惯性。触摸行星轻点打开卡片，拖动操作视角，避免误改日期；鼠标保留拖行星改变日期，并支持右键/中键平移。取消、失去捕获和窗口失焦统一清理状态。

手动观察停止当前课程镜头动画，暂停讲解以免下一段抢回镜头。惯性按真实帧时间计算并限制异常速度。旋转、世界矩阵与标签投影按同一帧顺序更新，减少重复 DOM 写入和隐藏图层计算。

## 验证与发布

录制旧版双指轨迹作为基线；用浏览器原生触摸事件验证缩放、平移、混合操作、1→2→1/3 指切换、取消、缩放边界、焦点切换、鼠标和点按卡片。对比状态连续性和主线程工作；自动化无法替代实体手机的 GPU/触摸体验，最终由测试环境实际体验验收。只部署测试 4.0.7，正式版保持 4.0.6，维护数据不改动。

## 验证结果

- 旧版基线（`.deploy-check/solar-gesture-baseline.cjs`）：双指平移 36×12 像素时，相机未平移，Z 旋转变成 -0.82 rad；松手 300 ms 后变为 -9.237 rad。明确复现了双指坐标相互覆盖及错误惯性。
- 修复后相同轨迹：相机平移约 -8.394 / +2.798 世界单位，旋转和日期变化为零，松手后无漂移。
- `.deploy-check/v407-gestures.cjs` 在本地和公网测试站、1000 / 390 宽度下通过：双指中心锚定、2→3→2→1 换指、取消和窗口失焦、按住再松开不保留旧惯性、近距离聚焦时缩放不跳变、60 步混合手势、上下缩放边界、课程镜头中断、鼠标平移/滚轮/行星日期拖拽、星宿文字上的手势及轻点开卡片。
- 同一浏览器帧内注入 500 个 Pointer Events，渲染帧只执行一次旋转更新，最终位移正确。该项为合成事件合并验证；连续多指测试使用 Chromium 原生触摸输入。
- 标签改用 transform 定位，避免每帧修改 left/top 触发布局；世界矩阵在动画后统一计算，标签直接使用该矩阵；日期文字按秒更新，隐藏星空标签跳过投影。
- `.deploy-check/v404-check.cjs` 验证星座/星宿互斥与可全关、二分二至和当前节气标签；`.deploy-check/v406-axes.cjs` 验证课程 XY 轴跨章节和刷新保留。本地及公网相关回归通过，截图检查无异常。
- `node --check`（手势控制器、服务器及提取出的内联模块）、`git diff --check` 通过。
