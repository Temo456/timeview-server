# 4.0.15 测试版：北京升空开场

## 镜头设计

35 秒连续升空：天安门近景 → 北京中轴线 → 二三四五六环 → 北京全域 → 中国 → 大半个地球 → 完整地球 → 北极俯视 → 时间景观。

近景使用动画重建图，城市与地球使用有来源记录的卫星底图，环路使用 OSM 真实道路轮廓。底部署名明确区分近景重建。

## 实现

- Three.js 的同一相机沿连续曲线飞行，多级地理贴图随高度平滑替换。
- 附轻音乐；沿用有声优先、受限时点击开启声音、跳过、会话内不重复开场与重播。
- 网页使用压缩后的 720p faststart MP4；提供独立 1080p 成片。
- 最后数秒按屏幕尺寸微调地球显示大小；地球界面从影片的北向平滑转到当前时刻。
- 太阳系页面自然播放结束后进入地球视图；主动跳过时保留用户所在视图。
- 先更新测试环境供观看。

## 检查

关键帧检查近景、中轴线、五条环路、中国、地球与终场；媒体检查分辨率、时长、帧率、音轨、faststart 和 Range；浏览器检查音频、跳过、重播与结尾导航。
