# 可见地球的真实相机返回

## 原因与修正

4.2.2 中，`prepareTransitionExit` 在地球已处于画面内时立即返回。剩下的合成动画很晚才出现明显的大小变化；复现时点击 180ms 后相机仍为 `[0,0,200]`，页面已切换，而地球半径只从 7.24px 变为 8.02px。

- 所有普通返回都先保留太阳系画面，运行 850ms 的 Three.js 相机拉近。地球在画面外时先执行已有的寻回移动，再进入同一拉近路径。
- 根据地球视角目标位置和尺寸计算相机距离，用投影补偿保持地球连续移动；完成后用 450ms 衔接地球地图。
- 相机推进期间保留时间播放与倍率，后续交接继续使用实际时间状态。离开时保存原太阳系相机，以便再次切回时恢复观察位置。
- 手机目标几何包含地球视角的信息栏高度。减少动态效果继续即时切换；中途取消释放相机动画和输入。

## 验证

必须通过真实 UI 点击，检查地球仍在太阳系页面时的相机距离与地球投影半径；截图核对实际地球在变大。覆盖桌面顶部/底部入口、手机、WebKit、画面外返回、连续反向选择、日期/倍率与相机恢复。发布测试环境 4.2.3。

## 完成记录

- `tools/test-visible-earth-return.cjs` 在桌面、手机 Chromium 模拟与 Windows WebKit 中通过。实际点击返回后，仍处于太阳系时地球投影半径已超过原来的两倍，相机距离同步减小；同时通过画面外返回、取消、动态切换减少动画、运行时间与相机恢复检查。
- 课程月相日期、章节跨视图、暂停继续与回到现在的衔接检查通过。
- 已发布测试环境 4.2.3：`https://timeview.site/timeview-test/`。维护数据保留课程 revision 27、184 条音频；正式环境保持原版本。
- 公网缓存升级与真实页面点击回归通过：两次返回均进入 `zooming-earth`，共四次视图切换只加载一个文档，旁白音频从缓存读取，页面无 JavaScript 错误。
- 验证未包含实体 iPhone；手机检查使用浏览器设备模拟和 Windows WebKit。
